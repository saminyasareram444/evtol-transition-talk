# Gust-Velocity-Margin Safety Filter for eVTOL Transition

Slides of a talk by Samin Yasar, Department of Computer Science, The University of Alabama.

**View the presentation:** https://saminyasareram444.github.io/evtol-transition-talk/ (password required)

The slides are encrypted (AES-256-GCM, key derived from the password with PBKDF2-SHA256). The login page derives the
key in the browser, and a service worker (`sw.js`) decrypts the files as the slides load them. Use a normal (not
private) window of a current browser.

## Controls

- Right arrow or space: next animation step
- Left arrow: back
- O: overview of all slides
- F: full screen
